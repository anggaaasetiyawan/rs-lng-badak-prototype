## Overview

Project ini adalah prototype redesign website RS LNG Badak, rumah sakit di Bontang, Kalimantan Timur. Prototype dibangun sebagai single-page application dengan HTML, CSS, dan JavaScript murni.

### Tujuan Redesign

1. **Informasi darurat mudah diakses** - Nomor IGD dan lokasi tampil instan
2. **Navigasi berbasis kebutuhan pasien** - Bukan kategori blog, tapi task-based
3. **Modernisasi visual** - Desain bersih dan profesional
4. **Data terstruktur** - Poli, dokter, jadwal sebagai data terstruktur
5. **Mobile-first** - Performa tinggi di koneksi lambat
